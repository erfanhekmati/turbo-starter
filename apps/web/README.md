# Web

Next.js frontend for turbo-starter.

See the [root README](../../README.md) for setup (install, database, and running all apps).

## Commands

```bash
pnpm dev      # http://localhost:3000
pnpm build
pnpm lint
```

## Feature modules

Copy `src/features/_template/` when adding a new feature. See the root README for the folder layout.

## Design system

Component demos live at `/design-system` when the dev server is running.
